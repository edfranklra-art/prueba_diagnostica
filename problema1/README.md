# Problema 1: Analizador Léxico

Este programa identifica los componentes de una expresión aritmética (números, operadores, operandos y paréntesis) y verifica si los paréntesis están balanceados.

## Requisitos
* Tener instalado [Python 3.x](https://www.python.org/).
* No requiere librerías externas (solo usa la librería estándar `re`).

## Instrucciones de ejecución en VS Code

1. Abra la carpeta del proyecto en **Visual Studio Code**.
2. Abra el archivo `problema1.py`.
3. Ejecute el script haciendo clic en el botón **Run Python File** (icono de Play arriba a la derecha) o abra una terminal integrada y escriba:
   ```bash
   python problema1.py
